# 使用指南

[English](USER_GUIDE.md) · [简体中文](USER_GUIDE.zh-CN.md)

顶部“新建、打开、保存、另存为”处理 DOCX 文档。含未支持对象的外部文档需另存副本，以保护原件；编辑中断后启动应用可恢复草稿。

先选中文字，再设置字体、样式或使用 AI 助手。模板会新建可编辑文档，个人模板与素材保存在本机。

顶部 English / 中文 切换语言。确认后保留当前文档、PPT 和媒体，重新加载界面，清空撤销历史及未应用的 AI 预览；正文与文件名不改写。

“AI 服务”选择本机已登录 Codex，或填写自己的兼容接口地址、模型与密钥。生成后先预览，再应用。全文翻译和 AI 排版位于“工具”；原文发生变化时旧预览会失效。

“PPT 模板”可选择原创模板，也可“打开 PPTX”导入自己的演示文稿。编辑文字和页面后导出 PPTX 保存；导入时保留已有图形，暂不支持所有形状属性。

PDF、图片工具使用各自预览，可导出结果或插入 Word。PDF 转 Word 得到可编辑文字流，不保证复杂页面版式复原。

“个人云空间”选择已配置的 rclone 远端和文件夹，或连接 WebDAV/本机同步目录。上传会检查同名并回读校验；只读连接禁止上传。容量、限额、权限由实际服务决定。
