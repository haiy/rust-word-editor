# 安全与隐私

[English](../SECURITY.md) · [简体中文](SECURITY.zh-CN.md)

不要提交 API Key、Cookie、访问令牌、rclone 配置、私人文档或本地应用状态。公开版不提供内置账号或网盘容量。

配置保存在 `~/Library/Application Support/Rust Word/`。含密钥的文件限制为当前用户读写，界面只获知是否已设置密钥，不回传已存储的密钥。rclone 授权仍由用户本机配置管理。

只有用户主动发起 AI 操作，才会把选区、文档块或演示素材发送到所配置的服务。普通编辑无需联网。公开包仅提供原创模板；导入外部文件时需有使用权限，渲染组件禁用宏。

`--test-server` 无鉴权，仅用于隔离开发测试，应绑定回环地址，不向公网开放。漏洞请通过 GitHub 私密安全报告提交，不要在公开 Issue 粘贴凭据；若凭据泄露，应到服务提供方撤销。
